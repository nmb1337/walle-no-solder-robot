# AMS Lite PETG setup

No TPU is required. Grip comes from purchased rubber wheels, so there is no
TPU spool, TPU slicing profile, or AMS TPU feed in this project.

- A: yellow PETG for the body, head, arms, face panel and eye rings.
- B: black PETG for the base, motor clamps, electronic deck and side covers.
- If you only own one PETG colour, load it in A and print every part with it.

For fit parts, use 0.20 mm layer height, 4 walls, 30% gyroid infill and the
PETG manufacturer's normal A1 temperature profile. Structural fit prints
must be cooled and measured before using them as a template for the rest of
the shell.
